# 🐍 贪吃蛇进阶版

一个用单个 HTML 文件写成的贪吃蛇小游戏,无需安装,浏览器打开即可玩。

## 如何运行

直接用浏览器打开 `index.html`。

## 操作方式

| 按键 | 功能 |
|---|---|
| 方向键 / WASD | 控制移动方向 |
| 空格 | 开始 / 暂停 / 游戏结束后重来 |

## 游戏元素

- 🍎 苹果:吃到加 1 分,蛇变长,速度略微加快
- ⚡ 闪电:吃到加 2 分,获得 4 秒加速
- 🧱 障碍:每得 3 分会多出一块,撞到即游戏结束

撞墙、撞到自己或障碍都会结束游戏。最高分保存在浏览器本地(`localStorage`)。
